# Student BD Tools 🎓

A modern, TypeScript-powered utility suite designed to streamline academic tasks and workflows for students in Bangladesh.

[![Live Demo](https://img.shields.io/badge/demo-studentbd--tools.vercel.app-blue)](https://studentbd-tools.vercel.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

---

## ✨ Features

- **Academic Utilities**: Built-in tools for CGPA/GPA calculations, class routine management, and quick access to essential academic resources.
- **TypeScript Powered**: Fully typed for an enhanced developer experience, reliability, and code completion.
- **Fast & Lightweight**: High performance with minimal overhead.
