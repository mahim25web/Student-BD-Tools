# Student BD Tools

A TypeScript-based utility suite designed to streamline academic tasks and workflows for students in Bangladesh.

---

## 🚀 Features

- **Academic Utilities**: Features tailored for grade calculations, routine management, and resource access.
- **TypeScript Powered**: Fully typed for better development experience, reliability, and auto-completion.
- **Lightweight & Fast**: Built with minimal overhead for high performance.

---

## 📦 Installation

Clone the repository and install the dependencies:

```bash
git clone [https://github.com/mahim25web/Student-BD-Tools.git](https://github.com/mahim25web/Student-BD-Tools.git)
cd Student-BD-Tools
npm install
💻 Usage
Run the build script or execution command using npm:

Bash
# Run in development mode
npm run dev

# Build for production
npm run build
